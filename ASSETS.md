# PNG-картинки для замены

**[Открыть наглядную карту](asset-guide.html)** — превью всех 26 рабочих файлов. Открывается двойным кликом, сервер не нужен.

Все заменяемые иллюстрации лежат в `assets/images/` и имеют формат PNG. Просто заменяй файл своим PNG **с тем же именем**: пути в коде менять не нужно. Исходные SVG иллюстраций сохранены в `assets/source-svg/` и не подключаются к странице. Значки соцсетей подключены отдельно как локальные SVG из `assets/icons/`.

## Первый экран

Четыре отдельных слоя: фон `sky.png`, герои `sky-heroes.png` и две картинки травы `sky_grass_front_l.png` / `sky_grass_front_r.png`. Трава находится перед платформами у нижних краёв. Нижний край закрывает кремовая волна следующего блока. Все пользовательские PNG сохранены без изменения. Старый `hero-art.png` остался в папке как запасной плейсхолдер и не подключён.

Положение настраивается в `styles.css`, блок `.hero`:

| Переменная                                   | Что меняет                                     |
| -------------------------------------------- | ---------------------------------------------- |
| `--heroes-x` / `--heroes-y`                  | Смещение героев: плюс вправо / вниз            |
| `--heroes-width`                             | Ширина слоя героев                             |
| `--heroes-bottom`                            | Положение нижнего края платформ на десктопе    |
| `--grass-left-x` / `--grass-right-x`         | Горизонтальное положение каждой картинки травы |
| `--grass-bottom`                             | Отступ травы от нижнего края секции            |
| `--grass-left-width` / `--grass-right-width` | Размеры травы                                  |

Герои и трава не реагируют на мышь. Их расположение адаптируется к ширине окна. На телефоне герои расположены под текстом. В медиазапросах есть отдельные размеры и отступы для узких экранов.

Прозрачность нужна у героев, травы, base-art, forest и press-kit.

## Иконки

Соцсети расположены в подвале и не влияют на высоту первого экрана. Логотип `logo-y8.png` находится справа от логотипа игры, размер задаёт .partner-logo.

X, Discord и YouTube: `assets/icons/x.svg`, `discord.svg`, `youtube.svg`. Размер значка — 28 px, область нажатия — 44 × 44 px. Ссылки задаются в `site-config.js`, поля `x`, `discord`, `youtube`; пустые адреса отключают переход. SVG взяты из Simple Icons; источник и лицензия — в `assets/icons/README.md` и `LICENSE.md`.

Четыре PNG по 300 × 300: `icon-explore.png`, `icon-craft.png`, `icon-fight.png`, `icon-coop.png`. Используются в карточках Features; co-op также в плашке первого экрана. Заменяются под теми же именами. Размер на странице задаёт класс .icon.

## Нижний пейзаж

Блок About: слева `base-art.png`, справа `base-art-right.png`, позади обоих островков — `base-back.png` с непрозрачностью 5%. Все PNG заменяются независимо. `forest.png` используется только в секции трейлера.

Непрозрачность фона задаётся `--landscape-back-opacity: 0.05`. Текст расположен между островками, на узких экранах — над ними.

В `styles.css`, блок `.about`: `--landscape-left-x` и `--landscape-right-x` задают смещения (плюс — вправо); `--landscape-left-width` и `--landscape-right-width` — ширину частей. На мобильных экранах значения переопределяются, пейзаж расположен ниже текста. Реакции на движение мыши нет.

## Скриншоты

Файлы `screenshot-01.png` … `screenshot-05.png`. На десктопе одновременно видны 3, остальные доступны по точкам или горизонтальной прокрутке. На телефоне виден 1; доступны точки и свайп. Нажатие открывает увеличенное изображение; в нём доступны все 5 и клавиши ←/→.

Текущие дополнительные скриншоты — плейсхолдеры крафта и мира. Замени их настоящими игровыми кадрами. Для каждого кадра обнови alt, подпись и aria-label в index.html. Можно использовать 1920×1080, сохраняя 16:9.

## Остальное

- Для замены нужен настоящий PNG, не SVG с изменённым расширением.
- Сохраняй пропорции; width/height в HTML задают место до загрузки. При изменении пропорций обнови и CSS aspect-ratio.
- Фоны sky и forest подключены в styles.css; остальные файлы — в index.html.
- Логотип — `logo.png`. Прозрачные поля сверху и снизу скрываются через CSS aspect-ratio и object-fit; файл не изменён. Размеры задаются в .brand--small и .brand--hero.
- На постере трейлера логотип встроен в изображение. Поверх добавляется только кнопка воспроизведения.
- PNG обычно тяжелее SVG/WebP: сжимай финальные изображения без изменения формата. При замене с тем же именем обновляй cache хостинга, если он включён.
