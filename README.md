# ORION 2 SANDBOX — landing

Локальный адаптивный лендинг по предоставленному макету. Обычные HTML, CSS и JavaScript, без фреймворка, сборки и runtime-зависимостей. Рабочие изображения — PNG. Первый экран использует пользовательские PNG неба, героев и передней травы; остальные иллюстрации пока служат плейсхолдерами.

## Запуск

Нужен Node.js 18 или новее. Из этой папки:

```powershell
node scripts/serve.mjs
```

Открыть **http://127.0.0.1:4173**. Установка пакетов не нужна. В Windows также работает `npm.cmd run dev`. Остановка — `Ctrl+C`.

Сервер предназначен только для локальной разработки, слушает `127.0.0.1`. Для публикации достаточно статического HTTPS-хостинга; Node.js на нём не требуется.

## Где редактировать

| Файл             | Назначение                                       |
| ---------------- | ------------------------------------------------ |
| `index.html`     | Тексты, разметка, изображения, SEO-метаданные    |
| `styles.css`     | Оформление, CSS-переменные, адаптивные состояния |
| `site-config.js` | Steam, трейлер, пресс-кит                        |
| `app.js`         | Мобильное меню, галерея, диалог трейлера         |
| `assets/images/` | Все заменяемые иллюстрации                       |
| `ASSETS.md`      | Размеры и правила замены изображений             |
| `assets/fonts/`  | Локальный Nunito и лицензия OFL                  |

## Ссылки

Заполнить нужные поля в `site-config.js`:

```js
window.ORION_CONFIG = Object.freeze({
  steam: "https://store.steampowered.com/app/YOUR_APP_ID/",
  trailer: "https://www.youtube.com/watch?v=YOUR_VIDEO_ID",
  pressKit: "assets/orion-2-press-kit.zip",
  x: "", // Полный URL профиля X
  discord: "", // Приглашение Discord
  youtube: "", // URL канала YouTube
});
```

Для трейлера поддерживаются ссылки YouTube (`watch`, `youtu.be`, `embed`, `shorts`) и локальные/HTTPS-файлы `.mp4`, `.webm`. Плеер появляется только после клика. При закрытии он удаляется, звук останавливается. Для локального видео production-хостинг должен поддерживать byte ranges, если нужна перемотка.

При пустом URL ссылки неактивны. Steam показывает «Coming to Steam», пресс-кит — «Download Press Kit» без надписи «coming soon». В подвале находятся X, Discord и YouTube; после заполнения адресов они открываются в новой вкладке с `rel="noopener noreferrer"`. Пустой или неподдерживаемый URL трейлера открывает сообщение. Иконки соцсетей — локальные SVG в `assets/icons/`, без виджетов и внешних запросов. Источник и лицензия лежат в той же папке.

## Дизайн и доступность

- Секции и палитра следуют исходному макету; PNG можно заменять по одному под теми же именами.
- 4 колонки особенностей на большом экране, 2 на телефоне; остальные блоки перестраиваются без горизонтальной прокрутки.
- Нативный `dialog`: клавиша Escape, возврат фокуса к открывшей кнопке, стрелки в галерее, закрытие по подложке.
- Меню сообщает состояние через `aria-expanded`, закрывается по ссылке, Escape и клику снаружи.
- Видимый keyboard focus, skip-link, семантические заголовки, `alt` у изображений.
- Учтён `prefers-reduced-motion`. Основной текст доступен без JS, интерактивные медиа требуют JS.
- Размеры изображений заданы заранее. Нижние изображения загружаются лениво, hero — с высоким приоритетом.
- Один локальный variable WOFF2 со `font-display: swap`; запросов к Google Fonts у посетителя нет. Текущий subset — Latin, для русской версии нужен Cyrillic subset и `lang="ru"`.

## Перед публикацией

1. Заменить временные изображения, уточнить `alt` и тексты по фактическим материалам игры.
2. Добавить настоящие ссылки и проверить медиа. В текущем варианте они намеренно пусты.
3. В `<head>` указать абсолютный canonical, `og:url` и `og:image` после выбора домена. Для Open Graph нужен JPG/PNG 1200×630, не SVG.
4. Обновить год и правообладателя в footer при необходимости.
5. Опубликовать `index.html`, `styles.css`, `app.js`, `site-config.js`, `assets/`. `scripts/`, документацию и `package.json` размещать необязательно.
6. На хостинге включить Brotli/gzip, HTTPS и корректные MIME-типы. Для HTML/config — короткий cache; для изображений и шрифтов — длительный cache только с версионированием имён.

## Проверка кода

```powershell
npm.cmd run check
```

Проверяет синтаксис JavaScript и локального сервера. Отдельная браузерная проверка выполнена в headless Edge на ширинах 320, 390, 600, 768, 820, 1024 и 1440 px, включая меню, галерею и настроенные/пустые ссылки. Видеосервис и реальные загрузки не проверены: URL будут добавлены позже. Оценку Lighthouse не заявляем без отдельного измерения на production-хостинге.

## PNG и пять скриншотов

Все заменяемые картинки переведены в настоящий PNG; SVG-исходники сохранены в `assets/source-svg/`. На десктопе галерея показывает 3 из 5 изображений, на телефоне — 1 из 5; доступны точки переключения и горизонтальная прокрутка. Первый экран собран из отдельных слоёв sky.png, sky-heroes.png и sky_grass_front_l/r.png. Герои справа, трава впереди у нижних углов. Слои не реагируют на мышь; расположение адаптируется к ширине окна. Размеры и положение задаются переменными в .hero в styles.css. Подробнее — [карта картинок](asset-guide.html).
